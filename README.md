# 个人主页

**以下纯由Trae生成**

这是一个现代化、响应式的个人主页模板，专为GitHub Pages设计。包含丰富的动画效果、交互功能和美观的UI设计。

## 🌟 特性

- **现代化设计**: 采用渐变色彩、卡片式布局和流畅动画
- **响应式布局**: 完美适配桌面、平板和手机设备
- **丰富功能**: 包含导航、关于、技能、项目和联系等多个模块
- **交互体验**: 平滑滚动、技能条动画、粒子效果等
- **性能优化**: 使用CSS动画和Intersection Observer优化性能
- **SEO友好**: 语义化HTML结构和合理的meta标签
- **多页面结构**: 主页 + 二级页面（法术宝典、传奇事迹、魔法物品）

## 🚀 快速开始

1. **Fork或克隆这个仓库**
   ```bash
   git clone https://github.com/your-username/your-username.github.io.git
   ```

2. **个性化配置**
   - 修改 `index.html` 中的个人信息
   - 更新头像图片链接
   - 调整技能条百分比
   - 添加你的项目信息

3. **部署到GitHub Pages**
   - 将代码推送到你的GitHub仓库
   - 在仓库设置中启用GitHub Pages
   - 选择主分支作为发布源
   - 访问 `https://your-username.github.io`

## 🎨 自定义指南

### 修改个人信息
在 `index.html` 中搜索并替换以下内容：
- 姓名和标题
- 个人简介
- 联系方式
- 社交媒体链接

### 更新技能
在 `index.html` 的Skills部分修改：
- 技能名称
- 熟练度百分比
- 技能分类

### 添加项目
在Projects部分添加新的项目卡片：
- 项目图片
- 项目名称和描述
- 使用的技术栈
- 项目链接

### 调整颜色主题
在 `styles.css` 的 `:root` 部分修改CSS变量：
```css
:root {
    --primary-color: #667eea;    /* 主色调 */
    --secondary-color: #764ba2;  /* 辅助色调 */
    --accent-color: #f093fb;     /* 强调色调 */
    /* ... 其他颜色变量 */
}
```
